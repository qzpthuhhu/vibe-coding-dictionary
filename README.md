# Vibe Coding 视觉词典

> 80 个 AI 编程用得上的网页视觉概念 —— 每一个都在页面里**真实演示**，而不只是文字描述。

很多人让 AI 做网页时只会说「帮我做一个高级、简洁、有设计感的网站」。问题是「高级/简洁/有设计感」不是明确的网页结构，AI 不知道内容该怎么排、用户该怎么浏览和操作。

这个项目把网页拆成 **8 层 80 个概念**，并且——**每个概念都在这个网页自身上真实运行**。你看到的不是概念说明书，是概念本身在演示自己。

## 核心特性

### 探索学习模式（反向交互）
点击左下角放大镜（或按 `E`），鼠标移到页面任意区域，即时弹出讲解卡告诉你：**这块地方用的是什么视觉概念**。

讲解卡包含五部分：
- 概念编号 + 中英文名称
- 概念说明
- 适合场景
- **可直接复制的 AI 提示词** ← 这是核心价值
- 此处体现（本站哪里、怎么用的）

讲解卡可拖拽、可图钉固定、60 秒自动关闭。

### 概念层级区分
同一个区域往往嵌套多个概念（整块是「卡片式布局」，单张卡片是「3D 倾斜」）。系统区分两级：

| 层级 | 高亮框 | 触发方式 |
|---|---|---|
| 区域级 REGION | 黄色虚线大框 | 鼠标在区域空白处 |
| 元素级 ELEMENT | 橙黄实线发光框 | 鼠标精确停在小元素上 |

### 同一内容多套视觉
多个区域支持视图切换，用**同一份数据**渲染成**不同布局**，直观对比差异：

- 关键数据：Bento Grid ↔ 仪表盘 ↔ CSS Grid 12 列
- 产品矩阵：等高卡片网格 ↔ 真瀑布流（高度分三档）
- 发展时间线：垂直时间线 ↔ 横向滚动吸附
- 视觉风格画廊：10 种风格渲染同一组内容，支持逐个查看 / 并排对比

### 三大交互实验区
- **状态与反馈实验室**（概念 51-60）：骨架屏、懒加载计数、Spinner、进度条、加载按钮、空状态、错误状态、重试、乐观更新回滚、行内验证 —— 全部可反复触发
- **视觉风格画廊**（概念 61-70）：极简 / 杂志 / 瑞士 / 玻璃拟态 / 新野兽派 / 深色 / 双色 / 网格渐变 / 噪点 / 新拟态
- **高级效果实验场**（概念 71-80）：自定义光标、三档磁吸、可调角度 3D 倾斜、聚光灯、文字蒙版开关、裁切揭示重播、450 粒子网络动画、视图过渡、减少动态开关、真实性能指标

### 其他
- 完整深色模式（CSS 变量驱动，跟随系统 + 手动切换 + localStorage 持久化）
- 根字号 6 档响应式（1280–1499px 区间专门优化，16 寸笔记本无需手动缩放）
- `Cmd/Ctrl + K` 命令面板搜索 80 个概念
- 移动端组件演示区（手机模拟器内真实还原汉堡菜单 / 面包屑 / 底部导航）
- 尊重 `prefers-reduced-motion`

## 8 章 80 概念总览

| 章节 | 编号 | 内容 |
|---|---|---|
| 1 · 页面布局 | 1–10 | 卡片式、瀑布流、Bento Grid、分屏、CSS Grid、Flexbox、侧边栏、仪表盘、响应式、全出血 |
| 2 · 页面结构 | 11–20 | 单页、多页、落地页、案例页、Hero、功能网格、固定叙事、时间线、FAQ、页脚 |
| 3 · 导航切换 | 21–30 | 固定导航、汉堡菜单、面包屑、锚点、Tabs、侧边导航、超级菜单、底部导航、分页、返回顶部 |
| 4 · 常用组件 | 31–40 | Modal、Drawer、手风琴、Tooltip、Toast、轮播、灯箱、表单、命令面板、FAB |
| 5 · 滚动动作 | 41–50 | 滚动出现、视差、进度条、滚动吸附、横向滚动、无限滚动、跑马灯、悬停微交互、错峰、滚动驱动 |
| 6 · 提示加载 | 51–60 | 骨架屏、懒加载、Spinner、进度条、加载按钮、空状态、错误、重试、乐观更新、行内验证 |
| 7 · 视觉风格 | 61–70 | 极简、杂志、瑞士、玻璃拟态、新野兽派、深色、单色双色、网格渐变、噪点、新拟态 |
| 8 · 高级效果 | 71–80 | 自定义光标、磁吸、3D 倾斜、聚光灯、文字蒙版、裁切揭示、粒子、视图过渡、减少动态、性能预算 |

## 技术栈

- React 19 + TypeScript
- Vite 7
- Tailwind CSS v4（`@theme inline` + CSS 变量，无 `tailwind.config.js`）
- Framer Motion（动效）
- Radix UI（无障碍组件基元）
- Lucide React（图标）

## 本地运行

```bash
git clone https://github.com/qzpthuhhu/vibe-coding-dictionary.git
cd vibe-coding-dictionary
npm install
npm run dev
```

## 目录结构

```
src/
├── data/
│   ├── concepts.ts         # 80 个概念基础数据（编号/章节/层级/所属区域）
│   ├── conceptDetails.ts   # 80 个概念详解 + AI 提示词全文 ★核心资产
│   └── bytedance.ts        # 内容载体数据
├── components/
│   ├── HighlightProvider   # 高亮定位 + 讲解卡 + 探索模式核心逻辑
│   ├── ThemeProvider       # 深色模式
│   ├── SidebarIndex        # 左侧 80 概念索引
│   └── sections/           # 各内容区域
└── index.css               # CSS 变量 + 响应式根字号分档
```

## 只想要提示词？

不用跑起来。直接看 [`src/data/conceptDetails.ts`](src/data/conceptDetails.ts) —— 80 条概念的说明、适合场景和可直接复制的 AI 提示词都在里面，纯数据文件，无依赖。
